# Contact Management System

A contact management web application developed using PHP and CodeIgniter 4 as part of my university coursework at Technological University of the Shannon (TUS).

## Technologies Used
- PHP
- CodeIgniter 4
- SQL
- HTML
- CSS

## Features
- Add new contacts to a database
- View saved contacts
- Edit existing contact information
- Delete contacts
- Search contacts by name
- Form validation

## About the Project
This project was developed to practise server-side programming and database management.

It helped me gain experience working with PHP, connecting a web application to a database, and using the Model-View-Controller (MVC) architecture.

## Running the Project
This project uses CodeIgniter 4 and requires a local PHP environment and a configured database to run.
